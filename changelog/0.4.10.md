## Highlights

- **The skill triggers more often** (#77). The description now asks the agent to use it whenever a page would help more than plain text, even if text would also work. It names the shapes that did not trigger before: state machines, diagnoses, review findings, trade-offs and decisions, and any answer with a table or a ranked list. In a local test of 19 prompts the skill loaded in about 73% of runs, up from 54%; small talk and "plain text only" still do not trigger. It will now also trigger on some short answers.
- **Themes.** A theme file in `<AM_HOME>/themes/<name>.json` is picked like a built-in theme, and `am theme check` reports missing variables, invalid colors and low contrast (#68). A new `paper` theme has serif prose for reading (#71). The new default `theme: auto` picks `paper` for the doc template or a draft with no component block, and `blueprint` otherwise. A theme set in config still wins. The toolbar uses drop-down lists for theme and mode. Built-in themes are now defined in one place each (#67).
- **Chinese writing check** (#20, thanks @mzopedia): a short word list for typos (登陆 → 登录), vague quantities (尽快, 若干), 以上 / 以下 / 以内 after a number, and one-meaning-one-word choices (单击 → 点击). Warnings only; Japanese is skipped.
- **Easier to install.** `INSTALL.md` is a guide written for AI agents: it installs the plugin in Claude Code and the skill in other agents, keeps an existing install, asks nothing, and ends with one report. The one-prompt install in the README now points to it, and the install smoke test runs its commands (#72).
- **Links that open.** The reply ends with a `file://` Markdown link, so GUI hosts such as Codex and Antigravity show a clickable link (#76). The page is rendered before the reply, so the turn ends with text (#75).

## Notes

- Pages made with earlier versions keep their look until you render them again.
- The default theme can change: a doc-template page, or a draft with no component block (`flow`, `sequence`, `callout` and so on) or raw html / svg, now gets `paper`. A Markdown table alone is not a component block. Set `am config set theme blueprint` to keep the old look.
- The slash command for settings depends on how you installed: `/answer-me-with-html:config` for the plugin, `/answer-me-with-html config` for the skill (#70).
