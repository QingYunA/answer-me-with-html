## Write a component as a ::: block

A component written the way VitePress and Docusaurus write an admonition now renders exactly like the fenced block, instead of the error 0.5.9 reported (#341):

```markdown
:::callout ok Done
It works.
:::
```

is the same as

````markdown
```callout ok Done
It works.
```
````

- Only a component name counts: `:::note`, a bare `:::`, and `:::` inside a code block stay text.
- The block ends at a line of at least as many colons as its opener, so a block that opens with `::::` can hold a `:::` line.
- An opener with no closing line is the same error as an unclosed ``` block.
- The docs still teach the ``` form; `:::` is accepted so a draft written from habit renders the first time.

**Full list:** #341.

## 组件也可以写成 ::: 块

按 VitePress、Docusaurus 提示框的写法写的组件，现在和 ``` 代码块写法渲染结果完全相同，不再像 0.5.9 那样报错（#341）：

```markdown
:::callout ok Done
It works.
:::
```

等同于

````markdown
```callout ok Done
It works.
```
````

- 只有组件名才算：`:::note`、单独的 `:::`，以及代码块里的 `:::` 照旧是文字。
- 块在冒号数不少于开头的那一行结束，所以用 `::::` 开头的块里可以写 `:::` 行。
- 有开头没有结尾，和 ``` 没闭合报同一个错。
- 文档仍然教 ``` 写法；接受 `:::` 是为了让按习惯写的草稿一次就能渲染成功。
