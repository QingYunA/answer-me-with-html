## Highlights

- **Photo-wall layout for sheet pages** (#56, spec #50). Panels now arrange themselves in the browser like a justified photo wall: every row fills the page width and its panels end at the same line. A wide table or diagram gets the width it needs instead of scrolling sideways, and a short panel can stack beside a tall diagram. Panel order never changes. `span` and `rows` are now hints. Narrow screens keep one column, printing falls back to the plain grid, and with JavaScript off the page keeps its current layout. Layout takes about 10–60 ms.
- **Callout syntax check** (#55): a callout body that starts with `type: info` (or `warning`, `error`, `note`) now fails with the correct syntax instead of printing "type: info" as text.
- **Accessible names in the page language** (#58, fixes #47): diagrams and the table of contents are named in the draft's language instead of always Chinese.
- **ElevenLabs** (#48): updated defaults, `ELEVENLABS_MODEL_ID`, and a setup guide.

## Notes

- Pages made with earlier versions keep their old layout until you render them again. `am patch` re-renders a page with the new script.
- New pages carry about 6 KB more script, and panels with an explicit `span` get a `data-span` attribute.
