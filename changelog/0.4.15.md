## Highlights

- **Change markers in `flow` and `tree`** (#125). Start a line with `+ `, `- ` or `~ ` to show what a plan adds, removes or changes. The page draws one diagram in a Changes view, with a Before / Changes / After switch and a count row. Pages without markers are byte-identical.
- **Project website** (#126): https://qingyuna.github.io/answer-me-with-html/ (Chinese at `/zh/`). Its playground runs the real renderer in your browser.
- **A lighter `SKILL.md`** (#127). The settings and video instructions moved to `references/`, and the agent reads them only when you change settings or ask for a video. `SKILL.md` drops from 19.5 KB to 16.2 KB, so each first page in a session costs less to load. Page answers are unchanged.

## Fixes

- The diagram expand button sits on its own row and no longer covers the drawing (#124).
- The MP4 export test gives Chrome more time to start, so CI stops failing on slow runners (#132).

## Docs

- The README token claim now comes from a fixed corpus: hand-written HTML averages 4,893 tokens and the Markdown draft 612, about 1/8. The README also explains why the bill drops less than the tokens (#127).
- A comparison with Archify and dsh-genui: [docs/compare.md](https://github.com/QingYunA/answer-me-with-html/blob/main/docs/compare.md) (#127).
- Jump links at the top of the README; details moved to the [reference](https://github.com/QingYunA/answer-me-with-html/blob/main/docs/reference.md) (#130, #131).
