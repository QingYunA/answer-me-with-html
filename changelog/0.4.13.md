## Highlights

- **Answer on the page** (#100). An `ask` block puts a decision in the panel it changes, with the agent's suggestion selected. Every panel gets a comment button and every page a Reply button, which copies one message with the reader's answers and comments to paste back to the agent. Answers survive a reload.
- **Code blocks that quote real files** (#99). ```` ```ts src=server/routes.ts lines=18-30 hl=22 ```` reads the lines from the file, so the model types no code. Blocks get line numbers, highlighted lines and a Copy button. Key files (`.env`, `*.pem`, `.ssh/` …) and files that hold a token are never quoted, and the render lists every file it embedded.
- **Local images as captioned figures** (#95). An image alone on its line, `![what it shows](/path/to/file.png)`, becomes a figure with the alt text as caption, embedded in the page so it still opens offline. A missing, non-image or oversize (> 5 MB) file stops the render at its line. Paths with spaces work (#106).
- **Diagram viewer** (#57, #109). Each flow and sequence diagram has an expand button that opens it in a lightbox with zoom and pan. Its labels follow the page language. Thanks @Cham1229.
- **Placeholders stay visible** (#110). `ssh user@<host>` or `kill <pid>` used to lose the words, and a `<script>` or `<style>` in prose swallowed the rest of the page. Raw HTML in a draft is now filtered: unknown and page-breaking tags show as text, deliberate markup (`<kbd>`, `<br>`, `<details>` …) stays, and kept tags lose event handlers and `javascript:` links. The render lists every tag it changed. Thanks @SU-AN-coder, who found it in #108.

## Fixes

- A page served inside another document (claude.ai Artifacts) gets its theme, mode and language back (#104). Thanks @enzo-wego.
- A status word in a table cell may be followed by inline code, bold or a link and still becomes a badge (#101).
- Image-like text is checked only where Markdown is read, so `![a](b)` in a tree label, a raw `html` block or diagram text no longer fails the render (#107).

## Notes

- Every page now has a Reply button in the toolbar and a comment icon in each panel title bar, and its footer links to this repository (#94). Pages made with earlier versions keep their old look until you render them again.
- A draft that relied on a non-text-level tag inside a sentence, an unknown tag or an event handler now gets text and an `[html]` warning instead.
- The README has a section on making the skill less proactive (#93) and a plain-text vs page comparison image (#94).
