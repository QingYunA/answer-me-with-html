## Make a theme with your agent

Open **[answer-me-with-html.com/themes](https://answer-me-with-html.com/themes/)**, click "Make your own theme", and paste the prompt to your agent:

```
Make me a theme for Answer me with HTML that looks like: <describe the look>.
Follow https://answer-me-with-html.com/themes/make.md
```

- The agent starts from the closest catalog theme. It saves the new theme to your themes folder, checks it with `am theme check`, and shows you light and dark specimen pages. You can use the theme right away.
- When you are happy with it, the agent gives you a prefilled "Submit a theme" issue. A bot checks the theme on the issue. A maintainer reviews every theme before it goes into the catalog.
- You can also edit a theme by hand in the [theme editor](https://answer-me-with-html.com/themes/new/), or open a pull request. See [CONTRIBUTING.md](https://github.com/QingYunA/answer-me-with-html/blob/main/CONTRIBUTING.md#theme-catalog).
- `/llms.txt` points agents at the guide and the docs.

## `am serve` reloads pages

A page that you open through an `am serve` link reloads by itself when its file changes: `am patch`, a new render to the same file, or an editor save. If you have answered, commented or marked anything, it does not reload, so your input stays (#204).

## Security

- Every page and video carries a Content-Security-Policy that allows only its own scripts, by hash. Nothing loads from another site (#244).
- Code quoting (`src=`) and images check the real file behind a symlink. A secret folder or a password inside a URL is refused. An image must be the type its extension claims (#243).

## Other changes

- When Node.js is missing, the install guide shows the exact command for your system and asks once before it runs it. It also explains errors from an old Node.js (#246, #247).
- The skill's writing section now starts from one rule: every sentence gives the reader one fact they need (#248).
- New versions are checked once a day instead of once a week (#253).
- When `am serve` prints a link, an agent that has an in-app browser opens the page there (#231).

## 让 agent 帮你做主题

打开 **[answer-me-with-html.com/zh/themes](https://answer-me-with-html.com/zh/themes/)**，点"做一个自己的主题"，把提示词发给你的 agent：

```
帮我给 Answer me with HTML 做一个主题，风格是：<描述你想要的样子>。按 https://answer-me-with-html.com/themes/make.md 的步骤做。
```

- agent 从主题库里最接近的主题改起，把新主题存进你的主题文件夹，用 `am theme check` 检查，再给你看浅色和深色样张。新主题马上就能用。
- 你满意之后，agent 给你一个预填好的"Submit a theme" issue。issue 上有机器人检查主题。每个主题进主题库前都由维护者审核。
- 也可以在[主题编辑器](https://answer-me-with-html.com/zh/themes/new/)里手动改，或者提交 PR，见 [CONTRIBUTING.md](https://github.com/QingYunA/answer-me-with-html/blob/main/CONTRIBUTING.md#theme-catalog)。
- `/llms.txt` 把 agent 指向这份说明和文档。

## `am serve` 自动刷新页面

通过 `am serve` 链接打开的页面，文件变化时会自动刷新：`am patch`、重新渲染到同一个文件、或者编辑器保存都算。如果你已经回答、评论或标记过内容，页面不会刷新，你的输入会保留（#204）。

## 安全

- 每个页面和视频都带上内容安全策略（CSP），只允许运行自带的、按哈希固定的脚本，不从其他网站加载任何东西（#244）。
- 引用代码（`src=`）和图片会检查符号链接背后的真实文件。路径经过敏感目录、或者文件里有 URL 中的密码，都会拒绝。图片的实际类型必须和扩展名一致（#243）。

## 其他改动

- 没有 Node.js 时，安装说明会先给出适合你系统的确切命令，问你一次再运行；Node.js 版本太旧时会解释报错（#246、#247）。
- skill 的写作部分改成从一条原则出发：每句话只给读者一个需要知道的事实（#248）。
- 新版本检查从每周一次改为每天一次（#253）。
- `am serve` 输出链接时，有应用内浏览器的 agent 会直接在里面打开页面（#231）。
