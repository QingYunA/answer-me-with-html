## Fixes

- Table headers in right- and center-aligned columns now follow the column alignment (#31, fixes #28).
- `am clean` skips symlinked roots, so it never deletes files outside the data directory (#27).
- SVG diagrams stay readable when the theme context is lost (#21).
- `am patch` keeps the page's STE style instead of falling back to the config (#16, #22).
- The SKILL.md description fits the 1024-character limit (#26).

## Internal

- New page envelope module (`src/page.js`), one output path for render / video / patch, one place for override checks and the voice list (#24). Generated HTML is unchanged.
- Patch round-trip invariant tests (#24).

The `am video` summary line now also prints the theme.
