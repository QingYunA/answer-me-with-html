<!-- release 0.4.11 2026-10-06 -->

## Highlights

- **One plugin instead of two** (#81). The separate `answer-me-with-html-always` plugin is removed. Always-on mode is now one rule that you paste into `~/.claude/CLAUDE.md` or `AGENTS.md`; delete the rule to turn it off. The skill still recognizes the `[answer-me-with-html always-on]` marker, so the behavior is the same. The README has the rule, and the Install section now points to it.
- **Fewer flaky Chrome tests** (#80). The Chrome tests fail less often, and say why when they do.

## Notes

- **If you installed `answer-me-with-html-always`:** your copy keeps adding the reminder until you remove it. Run `/plugin uninstall answer-me-with-html-always@answer-me-with-html`, then paste the rule from the README ("Always-on mode") if you still want it.
- The `always` setting is gone from `am config`. An old `config.json` that still has it is ignored, so nothing breaks.
- Pages and videos are unchanged: a snapshot of 432 render, video and patch combinations shows no difference from 0.4.10.

## Update

- Plugin: `claude plugin update answer-me-with-html@answer-me-with-html`
- Skill: `npx skills update answer-me-with-html -y`
