## Highlights

- **Traditional Chinese** (#89). A draft with `lang: zh-TW`, `zh-Hant`, `zh-HK` or `zh-MO` gets Traditional page buttons, theme names and video player labels, and Traditional fonts in front of the Simplified ones, so systems whose default Chinese font is Simplified still draw Traditional glyphs. A draft that does not say is recognized by characters written in only one form; text made of shared characters stays Simplified.
- **One place decides the language** (#88). `lang: zh-tw` used to give `<html lang="en">` with Chinese labels, and `lang: fr` gave Chinese labels too. A tag is now written as declared (`zh-tw` and `zh_TW` become `zh-TW`), a bare `zh` still gives `zh-CN`, and a language without its own labels gets English labels with its own `lang`. A language is now one file in `src/languages/`.
- **More languages detected** (#90). Korean, Russian, Arabic, Hebrew, Thai and Greek drafts get their own `lang` instead of `zh-CN`. Latin-script text is still English, so declare `lang: fr` (or `es`, `pt` and so on) for those.
- **`am patch` keeps the language of the page** (#90), so patching a panel with plain text no longer flips a Traditional Chinese page to Simplified.
- **The writing check follows the language** (#90). A language other than Chinese, English and Japanese gets only the length rules: sentences in words (characters for CJK text), paragraphs in sentences. The English passive-voice rule and the word lists no longer run on it.
- **Narration follows the language** (#90). A declared language applies to every line; otherwise each line is read in the language of its own text. Traditional Chinese lines use the Chinese voice.
- The README now recommends always-on mode (#83).

## Notes

- The CSS inside every page changed: font rules use `:lang()` ranges, and there are Traditional Chinese rules. Pages made with earlier versions keep their old CSS until you render them again. `ja-JP` pages now get the Japanese fonts too (the old rule matched only `ja`).
- The system-voice cache (macOS `say`, `espeak-ng`) is rebuilt once, because the language is now part of its key. ElevenLabs and a local server keep their cache keys, so nothing already paid for is synthesized again.
- Arabic script also writes Persian and Urdu, and Cyrillic also Ukrainian: without `lang:` those drafts are tagged `ar` and `ru`.
- Traditional Chinese glyphs are checked in Chrome and WebKit on macOS (`zh-TW` and `zh-Hant` draw the same glyphs, and a named Simplified font does not override the language). Firefox and Windows are not checked yet.
- Not in this release, tracked separately: wrapping Korean and Thai text in diagrams (#85), picking narration voices by locale (#86), right-to-left layout (#87).
