<!-- release 0.5.2 2026-10-12 -->

## Highlights

- **DeepSeek Harness plugin** (#199, #200). Install with `dsh plugin --profile <profile> add github:QingYunA/answer-me-with-html`, using the profile you run in (`web` is the shipped one). The package declares a `dsh.bundle` patch that mounts its own `skills/` directory as a skill provider, so nothing is copied into `~/.dsh/skills`.
  - DSH's plugin page shows the logo and an English and Chinese title and description.
  - When the agent has DSH's `present` tool, it hands over the page path, so you open the page from a card in the sidebar.
  - Thanks @wjvalue for the DSH work in #193.
- **The update command for DSH installs** (#198). The update hint and the new-version popover give the exact `dsh plugin --profile <profile> up <package>` command for an install inside a DSH profile.
- **A refined logo** (#195).

## Fixes

- Remark mode: a mark on a horizontal timeline item now has the same key at every window width. Before, a mark made in a wide panel was missing in a narrow one and left out of the Reply (#197).
- CI now runs every browser test file in the video job (#192).

## Docs

- The READMEs and the website list DeepSeek Harness among the install options (#202). INSTALL.md has a DSH section.
- The website footer links the Discord server (#201).

## Update

- Plugin: `claude plugin update answer-me-with-html@answer-me-with-html`
- Skill: `npx skills update answer-me-with-html -y`
- DeepSeek Harness: `dsh plugin --profile <profile> up answer-me-with-html`
