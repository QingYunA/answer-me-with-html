## Theme catalog

Themes now have a home: **[answer-me-with-html.com/themes](https://answer-me-with-html.com/themes/)**. Each theme has its own page with a live preview in light and dark.

```
am theme add comic --use
```

- `am theme add <name>` downloads a theme from the catalog, checks its size, sha256, colors and contents, and saves it. `--use` also makes it your default theme.
- `am theme list`, `am theme update` and `am theme remove`. `update` never overwrites a theme file you edited.
- Only catalog names are accepted, never a URL. A theme may not load anything from the network, so pages keep working offline.
- The first three themes: **comic**, **manga** and **pop**. Their headings use the Bangers font, which the page carries inside itself.
- On an older version, the theme page shows a one-line manual install.

## Themes can restyle diagrams

New optional diagram tokens let a theme change nodes, edges, sequence actors, notes, highlights and shadows: fill, stroke, line width, corner radius and hard shadows. Every token defaults to the current look, so built-in themes are unchanged. See "Diagram tokens" in the [reference](https://github.com/QingYunA/answer-me-with-html/blob/main/docs/reference.md).

## 主题库

主题有了自己的地方：**[answer-me-with-html.com/zh/themes](https://answer-me-with-html.com/zh/themes/)**。每个主题都有单独的页面，可以实时预览亮色和暗色。

```
am theme add comic --use
```

- `am theme add <名字>` 从主题库下载主题，核对大小、sha256、配色和内容后保存。加 `--use` 会同时设成默认主题。
- 另有 `am theme list`、`am theme update` 和 `am theme remove`。`update` 不会覆盖你改过的主题文件。
- 只接受主题库里的名字，不接受网址。主题不能从网上加载任何东西，所以页面离线也能正常打开。
- 首批三个主题：**comic（漫画）**、**manga（日漫）**、**pop（波普）**。标题用 Bangers 字体，字体内嵌在页面里。
- 旧版本在主题页上可以看到一行手动安装命令。

## 主题可以改图表了

新增一组可选的图表变量，主题可以改节点、连线、时序图的参与者、注释框、高亮和阴影：底色、线色、线宽、圆角和硬阴影。每个变量的默认值都是现在的样子，内置主题的外观不变。详见[参考文档](https://github.com/QingYunA/answer-me-with-html/blob/main/docs/reference.zh-CN.md)的"图表变量"一节。
